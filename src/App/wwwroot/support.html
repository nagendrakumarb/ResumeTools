Support & Technical Assistance

Professional Hub is an independent, client-side web application designed to run resume parsing and ATS matching tools entirely within your browser. If you encounter technical issues, feature bugs, or have feedback regarding our guides, use the resources below.

Frequently Asked Questions (Troubleshooting)

1. Why is my PDF or DOCX file failing to parse?

Because document processing occurs locally using WebAssembly, heavily encrypted, password-protected, or image-only scanned PDFs cannot be read. Ensure your document contains selectable text before uploading.

2. How do I clear cached application data?

If you experience unexpected behavior after an update, perform a hard refresh by pressing Ctrl + Shift + R (Windows) or Cmd + Shift + R (Mac), or clear your browser's site storage for professionalhub.co.in.

Before Submitting a Bug Report

To help us resolve issues efficiently, please follow these steps prior to submitting a ticket:

  • Test the action in an updated modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari).
  • Verify whether the issue persists with a non-sensitive sample document.
  • Note down your operating system, browser version, file format (.pdf or .docx), and exact error messages shown in the console (F12).
  • Privacy Caution: Do not attach personal resumes, private contact details, or sensitive employment information to public bug reports.

Official Contact Channel

All feature requests, bug reports, and content corrections are tracked publicly via our open-source project repository. Submit issues directly through the Professional Hub Issue Tracker on GitHub.

Scope of Support

Support is limited to application functionality and guide accuracy. We cannot provide legal advice, individualized career coaching, immigration consulting, or guarantee interview callbacks from third-party employers.
