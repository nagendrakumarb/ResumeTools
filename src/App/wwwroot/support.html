Support and feedback

Professional Hub is an independent browser-based project. Use this page to report a technical problem, suggest an improvement, or point out an error in one of the site guides.

Before reporting a problem

Try the latest version of a modern browser, then repeat the action with a non-sensitive sample document if possible. Note the file type, the page or feature used, what you expected to happen, and what happened instead. Do not include your resume, contact details, job description, API key, or other sensitive information in a public report.

Contact route

Submit a report or feedback through the Professional Hub GitHub issue tracker. Describe the issue in your own words and include only information you are comfortable sharing publicly. For a correction to a guide, identify the page title and the specific statement that needs review.

Scope and limitations

Support cannot provide legal, employment, recruiting, or immigration advice. The site can help explain its own checks, but it cannot confirm that a resume will be accepted by a particular employer or applicant tracking system.
